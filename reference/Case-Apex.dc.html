Spec 03 — Visual architecture

Shot like the machine, not like a catalogue

Form — the silhouette carried in near-black, edges read by light alone.
Detail — engineering shown close enough to feel machined.

Two frames, deliberately offset rather than aligned in a tidy row. The vertical stagger is how a scroll-driven page actually reveals imagery — one plate arrives, then the next enters from below it.

Spec 05 — Decisions

Four calls the system rests on

01 Monospace for everything but the name JetBrains Mono reads as instrumentation rather than marketing copy. Space Grotesk Bold is reserved for the marque, so the two voices never compete.
02 Three colours, one of them rationed Void and bone carry the entire interface. Signal red appears only where the system demands attention — never as decoration.
03 Scroll is the only control No carousel, no tabs. A 9:16 cinematic grid keyed to scroll position, so the reveal sequence is authored rather than browsed.
04 Spec labels, not headings Every section is numbered like a technical document. The page behaves like a spec sheet for the car, which is the point of the whole piece.
Spec 06 — Reflection

Where it stands

Apex is a visual and interaction study, not a shipped product. What it proves is that a restrained system — two typefaces, three colours, one scroll axis — can carry an experience usually attempted with far more moving parts.

What I would build next: the configurator as a working prototype. Right now the interaction lives in a composited frame, and the real test of the data HUD is whether it stays readable while values change.
